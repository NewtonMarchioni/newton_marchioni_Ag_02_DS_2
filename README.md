⚙️ Programa: Cadastro de Novos Colaboradores 

🧿 Objetivo: o cadastro.html é um formulário para o usuário preencher as informações:
      Nome completo;
      Idade;
      Profissão;
      Salário pretendido;
      Experiência anterior.
    O arquivo PHP deverá:
      Armazenar todos os dados em variáveis;
      Exibir as informações uma por linha;
      Gerar uma mensagem personalizada ao final.
      
Este projeto foi criado para a introdução a scripts lado servidor e ao PHP métodos GET e Post.

🀄 Após o preenchimento do formulário, ao apertar a tecla ENVIAR, uma nova tela retorna com os dados informados e uma mensagem padronizada:
Exemplo: "Newton, recebemos as informações e vimos seu interesse em trabalhar como Administrador.
A descrição de sua experiência:
Tenho experiência como gestor de empresas e trabalhei nos segmentos industrial, de serviços e financeiro.
Agradecemos seu interesse e entraremos em contato caso haja uma oportunidade."

📋 Instruções:
1. Informe Nome completo (text);
2. Informe Idade (number);
3. Informe Profissão (text);
4. Informe Salário pretendido (number - 0.01);
5. Informe Experiência anterior.
